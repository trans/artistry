Artistry 0.13.0 is committed on main (82a9805) but not tagged yet. It adds
indexes any plugin can define, and changes what your existing ones cover.
Nothing you call changes, but the first open of each store does some work:

- `register(index:)` still takes your arrays of field names (copious's
  `(index + ["id"]).uniq`, the workspace plugin's `["path"]`), one index
  per field as before. Those indexes now cover current versions only
  (`new_id IS NULL`), and each is recorded as a claim by the plugin that
  asked for it (`Registry.indexes(kind)` lists them).
- The first time 0.13 opens an existing store, it turns the old
  `idx_<plugin>_<kind>_<field>` indexes into those claims and rebuilds
  them, and rebuilds `idx_artifact_new_id` over superseded rows only. It
  happens once: 475 ms on a 220,000-artifact test store, so a few
  milliseconds at your sizes.
- Open and close now run `PRAGMA optimize`, which writes SQLite's planner
  statistics (`sqlite_stat1`, `sqlite_stat4`) into the store when a table
  needs them. On a read-only store it's skipped. If Copious hands Artistry
  its own connection (`Artistry.open(db)`), Artistry doesn't close that
  connection, so it doesn't run optimize at close either; a long-running
  process can call `Artistry.optimize` now and then.
- New, if you want it: `Registry.add_index(kind, ["a", "b", ...], plugin:)`
  makes a composite index for a lookup you do often; `Artifact.where`
  fixing its leading fields reads one range of it. An index is shared by
  every plugin asking for the same fields, and `drop_index` removes it with
  the last claim. Field names are letters, digits, `_` and `-`, with `.`
  between nested names; others raise `Artistry::InvalidIndex`.
- An older artistry can still open a converted store; its `register`
  re-creates its old indexes beside the new ones, and 0.13 converts them
  again next time.

0.13.0 names jargon's new source just as 0.12.0 does, so the earlier advice
still holds: stay on 0.11.0 until memo releases with the new source, then
take 0.13.0 rather than 0.12.0.
