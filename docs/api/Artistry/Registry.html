    def self.allocate_code(db, kind : String) : String #

    Allocate a free one- or two-letter code for a kind name.

    Tries the first letter, then the first letter followed by each later letter of the name, then the first letter followed by A-Z. Codes are capped at two letters because slugs ("C42", "42C") are parsed that way.

    def self.register(kind : String, plugin : String, schema, description : String | Nil = nil, symbol : String | Nil = nil, index : Array(String) = [] of String, code : String | Nil = nil) : String #

    Register a new artifact kind. Returns the assigned code. Schema is a JSON Schema as any JSON-serializable value. Raises InvalidSchema if it can't be parsed, so it fails here rather than on every create. Index is a list of field names to create expression indexes on.

    #code declares the kind's code (one or two uppercase letters) so it doesn't depend on registration order. Without it, a code is allocated from the kind name. Raises InvalidCode, CodeConflict (another kind owns the code) or CodeMismatch (this kind is already registered under a different code).
